# GtaCraft 0.1.3 — Locate fix (English / Magyar)

## English

- **Search the current world:** menu Locate no longer sends an unintended F9 world switch while Franklin controls the natural Overworld.
- **Find the End above Los Santos:** `/locate structure minecraft:end_city` and the matching menu/custom search use completed rooftop End-city regions. `/gtacraft locate endisland` finds the built main island. Searches do not start/build an End fight.
- **Local searches in Los Santos:** loaded blocks, entities, POIs and waypoints are searchable in the mirror save. Natural-world generation searches remain available in the natural Overworld.
- **Clear teleport guidance:** under native Franklin movement, searches return coordinates and request **F7** Minecraft control before a menu teleport. This avoids reporting success when GTA would overwrite a server-only teleport.

Download **GtaCraft-0.1.3-EN.zip** or **GtaCraft-0.1.3-HU.zip** and update **both ASI and JAR**, with both games closed. Both packages include setup scripts, the updated Prism import, bilingual README, source and licenses. Existing arcade driving and other features are retained; protocol 15 is unchanged. The menu starts in English; Hungarian is selectable.

**GtaCraft-0.1.3-source.zip** contains the complete implementation. GitHub's automatic Source code archives contain this documentation repository. SHA-256 checksums are attached.

Both builds succeeded and 22 targeted offline checks passed. This update has **not** been run in retail gameplay; it is not a crash-free/full-playthrough guarantee. [Known issues](https://github.com/gta5craft/GtaCraft/blob/main/KNOWN_ISSUES.md) remain applicable.

## Magyar

- **Keresés az aktuális világban:** a menüs Locate nem küld téves F9-világváltást, amikor Franklin irányít a természetes Overworldben.
- **End Los Santos fölött:** a `/locate structure minecraft:end_city` és a megfelelő menüs/modparancs az elkészült rooftop End-városokat keresi. A `/gtacraft locate endisland` a megépült főszigetet találja meg. A keresés nem indít End-harcot és nem épít semmit.
- **Helyi keresések Los Santosban:** betöltött blokkok, lények, POI-k és mentett helyek. A természetes terep megtartja a generátoros keresést.
- **Teleportsúgó:** Franklin-irányítás mellett koordinátákat ad, és menüs teleport előtt **F7**-es Minecraft-irányítást kér. Így nem állítja, hogy sikerült egy teleport, amelyet a GTA azonnal visszaírna.

Az **EN/HU ZIP** azonos friss **ASI/JAR**-t, setupot, friss Prism-importot, kétnyelvű README-t, teljes forrást és licenceket tartalmaz. **Mindkét modfájlt együtt frissítsd**, a két játék bezárása után. A korábbi autós rombolás és többi funkció megmarad; protokoll 15. A menü angolul indul, magyarra kapcsolható.

A két build és 22 célzott offline ellenőrzés sikeres. Ez a javítás **még nem futott valódi játékpróbán**; nem teljes hibamentességi igazolás. Az ismert korlátok továbbra is érvényesek.
