# Complete corresponding source

Download **GtaCraft-0.1.2-source.zip** from [Releases](https://github.com/gta5craft/GtaCraft/releases). Both EN/HU gameplay packages also contain the same `source/` tree. This web repository presents the documentation and historical screenshots; the complete implementation is supplied as the source archive.

Read [BUILD](BUILD.md), [LOADER_MODIFICATIONS](LOADER_MODIFICATIONS.md) and [THIRD_PARTY](THIRD_PARTY.md). The custom loader binary is excluded. Its modified GPL source, pinned dependencies and patch are included; the helper expects a fresh upstream Git checkout as explained in LOADER_MODIFICATIONS. Proprietary SDKs and tools must be obtained separately.

A teljes forrás a fenti source ZIP-ben és mindkét játékcsomag `source/` könyvtárában szerepel. A webes repóban a dokumentáció és a korábbi képek böngészhetők.
