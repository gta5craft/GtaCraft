# GtaCraft 0.1.1 — Bedrock train collision

## English

- Stops/disables the train from the leading end's predicted contact with known bedrock, without waiting for unrelated unloaded terrain.
- Places the explosion effect on the first contacted bedrock face, including reverse travel. Bedrock is preserved.
- Prevents unrelated dense bedrock from exhausting the check before a reverse leading carriage.
- Shortens the English/Hungarian legal notice and includes the latest gameplay images.

Download **GtaCraft-0.1.1-EN.zip** or **GtaCraft-0.1.1-HU.zip**. Both contain identical gameplay files, full bilingual documentation, source and setup scripts. The menu starts in English; Magyar is selectable. **GtaCraft-0.1.1-source.zip** contains the corresponding implementation. GitHub's automatic Source code archives contain the documentation repository.

**Validation:** 46 controlled tests of the actual native controller and a successful full SDK build. No new retail gameplay test. Protocol 15 and Minecraft payload are unchanged; retain the supplied pair. Original licensed games and the external dependencies in the [README](https://github.com/gta5craft/GtaCraft) are required. [Known issues](https://github.com/gta5craft/GtaCraft/blob/main/KNOWN_ISSUES.md) remain applicable.

## Magyar

- Az elöl haladó vonatvég ismert bedrockkal való előre jelzett érintése megállítja/letiltja az egész szerelvényt. Mellékes, betöltetlen területekre nem vár.
- A robbanáseffekt az első bedrock felületre kerül hátramenetben is. A bedrock megmarad.
- Távoli bedrock nem fogyasztja el az ellenőrzési keretet a hátrafelé haladó szerelvény legelső vagonja előtt.
- Rövidebb angol–magyar jogi nyilatkozat és a legújabb bemutatóképek.
