# GtaCraft preview — English / Magyar

Documentation/package publication: **9 October 2026**. Gameplay pair: **7 October 2026 wallfix**, protocol **15**. This release refreshes documentation and packaging; it does not introduce newly built gameplay binaries or a new retail gameplay acceptance result.

Download **preview-EN.zip** or **preview-HU.zip**, extract it and read the README and setup instructions before using `Start.cmd`. Both packages contain the same mod pair, English/Hungarian documentation, source, licenses and setup scripts. Both menus start in English; select Magyar in **Insert → Status and keys → Menu language**. **source.zip** contains the complete corresponding implementation and loader sources. The automatically generated GitHub “Source code” archives contain this documentation repository; use our named source ZIP for the implementation.

Features include natural Minecraft terrain with native Franklin/vehicles, block building and weapon/explosion interactions in Los Santos, portals/world switching, car jump, Minecraft vehicle smoke/flames, XP/item presentation, native HUD ordering and a bilingual developer menu. The full README documents controls, architecture, supported behavior and limits.

**Requirements:** licensed GTA V **Legacy 1.0.3889.0** in Story Mode/DX11; licensed Minecraft Java **26.3**, Fabric Loader **0.19.5**, Fabric API **0.161.0+26.3**, Java **25 x64** with `--enable-native-access=ALL-UNNAMED`. ScriptHookV/dinput8, the archive-loader build and local collider mount must be prepared separately. The authored collider is included; the custom loader binary, proprietary SDKs and games are excluded. First-time setup is advanced, not a verified clean-machine one-click install.

**Known issues:** the final wallfix has no post-fix retail retest; stable Overworld ground-police pursuit remains unaccepted; spontaneous aiming/fire, native crash reports, seating/depth and climbing cases still need gameplay feedback. This is an experimental prerelease, not a bug-free release. See [KNOWN_ISSUES](https://github.com/gta5craft/GtaCraft/blob/main/KNOWN_ISSUES.md).

## Magyar

A csomag és dokumentáció dátuma **2026. október 9.**, a modpár az **október 7-i wallfix**, **15-ös protokollal**. Most a dokumentáció és a csomagolás frissült; új játékbináris vagy új játékbeli elfogadási eredmény nincs.

Az **EN/HU ZIP** ugyanazt a modot és teljes kétnyelvű leírást adja; mindkettő angol menüvel indul. Magyar váltás: **Insert → Status and keys → Menu language → Magyar**. A **source.zip** a teljes implementációt és a loader forrását tartalmazza. A GitHub automatikus „Source code” archívumai a dokumentációs repót adják: a tényleges kódhoz a névvel ellátott source ZIP-et töltsd le.

Saját eredeti játékok és a fenti pontos verziók szükségesek. A natív archívumloadert külön kell fordítani, a collider mountot külön előkészíteni; a collider bekerült, loader-bináris, SDK és játék nincs a csomagban. Új gépes telepítéshez technikai előkészítés kell.

Ez **kísérleti előzetes**. A földi rendőrüldözés, a végső faljavítás játékbeli visszamérése és a dokumentált lövés/crash/beszállás/mélység/kapaszkodás esetek nyitottak. A README angol leírása alatt teljes magyar változat, továbbá telepítési útmutató, kreditek, jogi nyilatkozat és ismert hibák találhatók.
